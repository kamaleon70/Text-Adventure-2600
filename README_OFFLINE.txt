TEXT ADVENTURE 2600 - OFFLINE WINDOWS EDITION
================================================

REQUIREMENTS

- Windows 10 or later
- A modern web browser

No Internet connection, Git, Node.js, Python, DASM installation, or
administrator access is required.


STARTING THE EDITOR

1. Extract the complete ZIP archive to a folder.
2. Double-click "Start Text Adventure 2600.bat".
3. The editor will open in your default browser.
4. Keep the command window open while using the editor.
5. Press Ctrl+C in that window, or close it, when you are finished.

The local server accepts connections only from this computer. If port 8765 is
already occupied, it automatically tries another nearby port.


PROJECT FILES AND ROMS

Use the editor's Load/Save controls to open or save project JSON files. Built
Atari 2600 ROMs are downloaded through your browser in the normal way.


TROUBLESHOOTING

- Do not run the launcher from inside the ZIP preview. Extract everything first.
- If the browser does not open automatically, use the local address printed in
  the command window (normally http://127.0.0.1:8765/).
- If Windows asks which network can access the server, no public-network access
  is needed. The server binds only to the local loopback address.
